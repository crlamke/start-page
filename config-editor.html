Page layout

The order of the boxes on the start page. Drag a box to a new place, or use its ← → buttons. Click a box's name to edit it. The start page fits as many boxes in a row as the window allows; here they are shown four to a row.

    Link boxes

    Each group is a box on the page, listed here in page order; ↑ ↓ move a box earlier or later on the page. Set a group's Shown inside to another group to make it a collapsible list inside that box instead.

    Search

    Search engines

    The search URL is everything up to the search words, for example https://duckduckgo.com/?q=. The first engine is the default.

    Weather

    Needs an OpenWeather API key in secrets.js. To find coordinates, right-click a place in Google Maps or OpenStreetMap and copy the latitude and longitude.

    RSS feeds

    RSS and Atom feeds both work. If a feed's box says it could not be loaded, the site doesn't let pages read its feed; a CORS proxy (below) gets around that.

    Notepad

    A box for quick notes, with New, Open, Save and Save as for text files. What you type is also kept as a draft in the browser, so a reload doesn't lose it. In Chrome and Edge, Save writes back to the file you opened; in other browsers it downloads the file.

    Alarm clock & timer

    Alarms and timers are set on the start page itself and kept in the browser. When one rings the page flashes and beeps, with Dismiss and Snooze. When the start page isn't in front, the tab title and icon flash and you get a desktop notification, or the browser's own OK/Cancel dialog.
